# Changelog

## 0.4.0

Research-driven enrichment of v0.3.0. Kept the skill style-neutral and cross-stack.

- Added design sense as educated intuition, strengthened by deliberate observation, making, feedback, and reflection.
- Added the learning loop: notice → collect → deconstruct → reproduce to learn → adapt → judge/reflect.
- Added explicit rationale for consequential decisions: decision, reason, trade-off, and confidence/evidence type.
- Clarified that aesthetic judgments can be contextual or subjective; do not fabricate objective/scientific rationales.
- Added optional 2–3-way divergent exploration for ambiguous or high-stakes briefs; compare concepts on meaningful differences, not skin-deep styling.
- Added critique lenses for visual hierarchy, composition, affordance, information density, typography/colour, and brand/emotional fit.
- Added a neutral observation → interpretation → actionable fix format.
- Expanded research notes with source-specific findings and retrieval limitations.

This release does not import the entire Designer Skills Pack or impose speculative/sensory exercises on ordinary product UI.
